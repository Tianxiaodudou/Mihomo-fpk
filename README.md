# 显式代理 · MihomoProxy

**装在飞牛 fnOS 上的代理服务端。** 导入你的机场订阅后，局域网里的手机、电脑、电视盒子只要把代理地址填成 NAS 的 IP 与端口，就能让国内网站直连、境外流量走你选的节点——全部操作都在一个网页控制台里点几下完成。

基于 [Mihomo](https://github.com/MetaCubeX/mihomo)（Clash.Meta）内核，单文件 `.fpk` 安装包，同一个包同时支持 x86_64 与 aarch64，所有依赖离线打包，装完即用、无需联网下载组件。

> **为什么叫「显式代理」？**
> 它不启用透明代理、不创建虚拟网卡、也不修改系统代理设置。客户端需要**手动填写**代理地址，属于标准的 HTTP / SOCKS5 显式代理。因此，不支持代理设置的 App（部分游戏、系统级应用）不会自动走代理，需要系统提供代理能力或配合其他工具。

---

## 它能做什么

- **订阅管理**：支持订阅链接、订阅文件（`.yaml` / `.txt` / `.json` / base64）、直接粘贴内容或拖拽文件导入；**同一时间只激活一个订阅**（节点列表只显示激活订阅的节点），其余订阅作为备用；卡片可上下排序（↑ ↓），支持定时自动更新与**自动切换订阅**。
- **节点与策略组**：展开策略组查看与切换节点，一键测速并显示延迟，绿色标记当前生效节点。
- **智能分流（离线可用）**：内置直连规则集，国内网站默认直连、境外走节点，不折腾。
- **规则可更新**：设置页可一键从上游拉取最新分流规则，**无需升级应用**。
- **网关管理面板**：走飞牛统一网关，不额外占用端口；支持日间/夜间主题、代理地址一键复制、网络连通性测试、配置预览、运行日志。

## 安装

1. 到 [Releases](https://github.com/Tianxiaodudou/Mihomo-fpk/releases/latest) 下载最新的 `MihomoProxy_<版本>.fpk`（可用同目录的 `SHA256SUMS.txt` 校验完整性）。
2. 飞牛 fnOS → **应用中心 → 手动安装** → 选择该 `.fpk` 文件。
3. 安装完成后打开：桌面图标，或浏览器访问 `http://<NAS-IP>/app/MihomoProxy`（已登录飞牛账号时会免密进入）。

> 内核总开关**默认关闭**，安装后不会自动开始代理，需要你手动开启（见下一步）。

## 快速上手（5 步）

### 1. 添加订阅
进入 **订阅** 页 →「添加链接」填入机场订阅地址 →「添加并拉取」。
也可以「导入文件」（选择 NAS 上的订阅文件）、「粘贴内容」，或直接把订阅文件**拖拽**到订阅页上。第一个订阅会自动激活。

> **一个订阅激活，其余备用**：同一时间只有一个订阅处于激活状态（卡片上有「已激活」标记），节点列表只显示激活订阅的节点；想用别的订阅，点它卡片上的「激活」即可。
> 卡片右上角的 **↑ ↓** 可以调整顺序，列表**越靠上越优先**成为「自动切换订阅」的备选。

### 2. 启动内核
回到 **概览** 页，打开 **总开关**。开启后内核才会真正开始对外提供代理服务；关闭会立即停止，但保留所有订阅与配置。

### 3. 选择节点
进入 **节点** 页 → 展开 **出口组** → 点你想用的节点右侧的「使用」即可切换出口；点「测速」或「全部测速」查看各节点延迟。
> 实际出口由「出口组」里选中的节点决定；点其他策略组里的节点只是设置该组的成员。

### 4. 拿到代理地址
**概览** 页 →「代理入口」会显示 `NAS-IP:7890`，这是 **HTTP 与 SOCKS5 共用的混合端口**，点「复制」即可。端口可在 **设置** 页修改。

### 5. 在客户端填代理
把上面这个地址填进需要走代理的设备或软件：

| 设备 / 软件 | 设置位置 |
| --- | --- |
| Windows | 设置 → 网络和 Internet → 代理 → 手动设置代理 → 地址填 `NAS-IP`、端口填 `7890` |
| macOS | 系统设置 → 网络 → Wi-Fi → 详细信息 → 代理 → 网页代理(HTTP) 与 安全网页代理(HTTPS) |
| Android | Wi-Fi → 长按当前网络 → 修改网络 → 高级选项 → 代理 → 手动 |
| iPhone / iPad | Wi-Fi → 当前网络 → 配置代理 → 手动 |
| 浏览器 | SwitchyOmega 等代理插件；或使用系统代理 |

只想让部分软件走代理时，用支持规则的浏览器插件或系统代理白名单即可。

## 分流规则（默认行为）

| 优先级 | 规则 | 去向 |
| --- | --- | --- |
| 1 | 内网 / 局域网 / 保留地址 | 直连 |
| 2 | 被墙域名（gfw 列表） | 订阅主策略组 |
| 3 | 国内域名与国内 IP | 直连 |
| 4 | 订阅自带规则 | 按订阅 |
| 5 | 其余流量 | 订阅主策略组 |

规则集随应用内置，**离线也可用**；上游为公开仓库 `Loyalsoldier/clash-rules`，过期时可在设置页手动更新。

## 日常维护

- **更新订阅**：概览页「立即更新全部订阅」，或在设置页开启**定时自动更新**（按小时）。
- **自动切换订阅**：设置页开启「自动切换订阅」后，当激活订阅的**全部节点都超时**时，会自动切换到列表中第一个可用的订阅（按卡片顺序，越靠上越优先），并在概览页显示切换记录；刚切换后 3 分钟内不会重复切换。
  - 开关打开后，设置页会出现「**自动切换参数**」卡片，可自行调整节奏（单位秒，默认值即推荐值）：**检测间隔**（默认 45，多久检查一次当前订阅是否还能用）、**单节点探测超时**（默认 5）、**切换冷却时间**（默认 180，刚切换后多久内不再切换）、**全部失败后的冷却**（默认 600，所有订阅都不可用时多久后再试）。该卡片有**独立保存按钮**，与页面其他设置互不影响。
- **更新分流规则**：设置页 →「分流规则」→「更新分流规则」。页面会显示规则版本、各规则集条数与最近更新时间；更新失败时会列出各镜像的具体原因，并始终保留原有规则。
- **修改端口**：设置页 →「代理端口」，保存后自动重建配置并重载内核（内核运行中会短暂重启）。
- **数据保存在哪**：订阅缓存与运行数据都在应用的私有目录 `/var/apps/MihomoProxy/var`，**升级或重装应用不会丢失**。

## 安全与使用边界

- 内核的管理接口只监听本机 Unix Socket，不对外开放。
- **代理端口默认监听 `0.0.0.0`，请仅在可信局域网内使用**，不要直接暴露到公网。
- 本应用不修改系统代理设置，也不做透明代理 / 虚拟网卡。
- 仅供个人在自有设备上使用；请遵守当地法律法规与订阅服务方的使用条款。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 打开面板黑屏 | 请从应用中心或 `/app/MihomoProxy` 入口打开；升级后浏览器可能缓存旧页面，强制刷新（Ctrl+F5） |
| 显示「内核已停止」 | 概览页打开「总开关」，开启后稍等几秒再看状态 |
| 测速全部超时 | 先确认内核在运行；再确认节点可用，或在节点页修改「测速链接」（默认 `http://www.gstatic.com/generate_204`） |
| 国内网站也走了代理 | 设置页更新一次分流规则；检查订阅里是否带入了过宽的规则 |
| 订阅拉取失败 | 看订阅卡片上的报错信息；先确认 NAS 能访问该地址，必要时用「导入文件」手动导入 |
| 客户端连不上代理 | 确认端口 7890 未被占用、客户端与 NAS 在同一局域网、NAS 防火墙已放行该端口 |

python tools/build.py            # 全流程：web → rules → go → mihomo → icons → stage → pack
